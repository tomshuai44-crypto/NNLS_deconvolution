# NNLS deconvolution

Fiji / ImageJ plugin for fixed-vector H/DAB color deconvolution using non-negative least squares (NNLS), with optional Gaussian DAB color selection.

- **Version:** 1.1.3
- **Contributor:** [tomshuai44-crypto](https://github.com/tomshuai44-crypto)
- **Plugin:** [NNLS_Deconvolution.jar](NNLS_Deconvolution.jar)

## Installation and use

1. Download [NNLS_Deconvolution.jar](https://github.com/tomshuai44-crypto/NNLS_deconvolution/raw/refs/heads/main/NNLS_Deconvolution.jar).
2. Copy it into your Fiji installation's `plugins` folder.
3. Restart Fiji.
4. Open a single RGB brightfield image and select **Plugins → Analyze → NNLS deconvolution**.

The plugin includes its DAB selection module. Python and a network connection are not required to run it.
